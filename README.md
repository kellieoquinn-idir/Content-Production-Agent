# Content-Production-Agent

## Scenario
Fieldstone Media is a content production agency.  
Current workflow:
- Researcher gathers sources into a shared doc  
- Writer drafts from those sources  
- Editor fact-checks line by line before publishing

## Problem
Fieldstone Media produces high-quality, well-researched posts but it takes 3 days of billable staff time and then limits how many clients can be taken on.
